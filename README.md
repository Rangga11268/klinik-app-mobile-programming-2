# Klinik App - Mobile Programming 2

Merupakan project slide materi dan tugas mata kuliah Mobile Programming 2 di Universitas Bina Sarana Informatika (UBSI).

## 🚀 Fitur & Modul Saat Ini (Pertemuan 2)
- **Data Poli:** Model, List Poli (`PoliPage`), dan Detail Poli (`PoliDetail`).
- **Data Pegawai (Tugas P2):** Model, List Pegawai (`PegawaiPage`), dan Detail Pegawai (`PegawaiDetail`).
- **Data Pasien (Tugas P2):** Model, List Pasien (`PasienPage`), dan Detail Pasien (`PasienDetail`).
- **Assets:** Konfigurasi folder gambar dan aset lokal (`assets/img/`).

## 🛠️ Tech Stack
- **Flutter SDK** (Dart 3.x)
- **Material 2 Theme** (`useMaterial3: false`, `primarySwatch: Colors.blue`)
